# AI Roles for Content Generation (Especially for Educators)

AI can serve as a powerful **Teaching Assistant, Content Creator, Instructional Designer, Research Assistant, Assessment Creator, and Learning Coach**. Below is a comprehensive list of AI roles for educators.

---

# 1. Curriculum Designer

AI helps educators design complete courses and training programs.

### Tasks

* Create Course Outlines
* Develop Syllabi
* Design Learning Paths
* Create Semester Plans
* Generate Weekly Lesson Plans
* Align Learning Outcomes with Bloom's Taxonomy

### Example

**Prompt:**

> Create a 45-hour Mobile Programming course using Flutter for Year 2 students.
